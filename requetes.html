Indicateurs stratégiques et requêtes SQL

Voici les indicateurs (questions 2 à 5 de l'étape 2) élaborés pour analyser la rentabilité et l'impact écologique de KDou.

Indicateur 2 : CA total généré avec les fournisseurs de l'UE

Objectif : connaître le montant total des ventes issues de produits européens.

Intérêt : privilégier les fournisseurs de l'UE permet de limiter l'impact lié au transport lointain.

Code SQL :

SELECT SUM(DC.Quantité * (P.CoutAchat * C.CoefMarge) * (1 - DC.[Remise (%)]) ) AS CA_Total_UE
FROM ((((DetailCommande AS DC
INNER JOIN Produit AS P ON DC.[Réf produit] = P.RefProd)
INNER JOIN Categorie AS C ON P.CodeCateg = C.CodeCateg)
INNER JOIN Fournisseur AS F ON P.NoFour = F.NoFour)
INNER JOIN Pays ON F.NoPays = Pays.NoPays)
WHERE Pays.UE = 'Membre';

Indicateur 3 : CA annuel pour desserts ou boissons

Objectif : chiffre d'affaires annuel généré pour les catégories desserts ou boissons.

Intérêt : analyser la rentabilité de ces familles de produits phares sur l'année.

Code SQL :

SELECT Year(Cmd.DateCde) AS Annee,
       SUM(DC.Quantité * (P.CoutAchat * C.CoefMarge) * (1 - DC.[Remise (%)]) ) AS CA_Annuel
FROM (((Commande AS Cmd
INNER JOIN DetailCommande AS DC ON Cmd.[N° commande] = DC.[N° commande])
INNER JOIN Produit AS P ON DC.[Réf produit] = P.RefProd)
INNER JOIN Categorie AS C ON P.CodeCateg = C.CodeCateg)
WHERE C.NomCateg = 'Desserts' OR C.NomCateg = 'Boissons'
GROUP BY Year(Cmd.DateCde);

Indicateur 4 : produits carnés non commandés

Objectif : calculer le nombre de produits carnés (viande) qui n'ont fait l'objet d'aucune commande.

Intérêt : identifier les produits à forte empreinte écologique qui ne se vendent pas, pour optimiser le catalogue.

Code SQL :

SELECT COUNT(P.RefProd) AS Nb_Viandes_Non_Commandees
FROM Produit AS P
INNER JOIN Categorie AS C ON P.CodeCateg = C.CodeCateg
WHERE C.NomCateg = 'Viandes'
AND P.RefProd NOT IN (SELECT [Réf produit] FROM DetailCommande);

Indicateur 5 : clients pilotes et partenaires

Objectif : vérifier si les clients pilotes d'un réseau partenaire ont autant de commandes que les clients partenaires.

Intérêt : évaluer l'efficacité de l'organisation logistique des livraisons groupées.

Code SQL :

SELECT C.CodeCli, C.Societe
FROM Clientele AS C
WHERE C.CodeCli IN (SELECT CodeCliPart FROM Clientele WHERE CodeCliPart IS NOT NULL);
