Rapport Web

Conception & design

Ce projet web a été codé uniquement en HTML et CSS, sans framework, avec une structure sémantique claire.

Nous avons choisi des couleurs sable et blanc pour le fond afin de rappeler l'univers de l'épicerie, et un brique doux pour les éléments interactifs (boutons, liens). Une image d'épices met le visiteur dans l'ambiance de KDou.

Structure des pages

Le site compte cinq pages : l'accueil, les missions, les requêtes SQL avec leurs indicateurs, le bilan, et cette page de rapport sur la création du site. Un en-tête avec la navigation et un pied de page sont présents sur toutes les pages.

Fichiers

Les pages HTML sont à la racine du projet et la feuille de style unique se trouve dans le dossier Assets, avec l'image d'arrière-plan.
